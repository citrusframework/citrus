## Named-server spike executed (T12-live — one-JVM A/B stays BLOCKED, three layers)

- Layer 1 (construction): one augmented application owns the JVM; two independent
  hosts in one JVM are impossible by construction.
- Layer 2 (qualifier): a second `@McpServer("poc-b")` feature set without declaration
  fails boot: `Invalid server names [[poc-b]]` (`McpMessageHandler.validateServerConfigs`).
- Layer 3 (declaration): the `servers.*` build-time map does not bind from
  configuration in 2.0.2 (quoted and unquoted syntaxes both warn "unrecognized key"
  and are ignored). With `invalid-server-name-strategy=IGNORE`, boot proceeds and the
  poc-b features (`echoB`, `poc://gamma`, `poc://delta`) are silently dropped while
  the default server serves alone — pinned by `QuarkusNamedServerIT`, which fails if
  any future release routes named servers (reopening the investigation).
